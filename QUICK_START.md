# ⚡ Quick Start — Video Editor Pro Max

30 segundos para empezar.

## Instalación

```bash
git clone https://github.com/Figstranmedia/editor-pro-max.git
cd editor-pro-max
npm install
npm run cli
```

## Eso es todo

El sistema automáticamente:
- ✅ Detecta tu proyecto (Next.js, React, etc)
- ✅ Extrae identidad de marca (colores, fuentes, tone)
- ✅ Sugiere carpetas necesarias
- ✅ Te guía para crear videos

## Flujo básico

```
1. npm run cli
   ↓
2. Elige: Crear video única vez O automatizar
   ↓
3. Describe lo que quieres
   ↓
4. Sistema sugiere plan respetando tu brand
   ↓
5. npm run dev (edita en Remotion Studio)
   ↓
6. npx remotion render <id> out/video.mp4
```

## Casos de uso

**Crear anuncio de feature:**
```bash
npm run cli
→ Crear un video
→ "Anuncio de nueva integración con Stripe"
→ Elige: TikTok / Instagram / YouTube
→ Done: Video respetando tu brand
```

**Automatizar contenido diario:**
```bash
npm run cli
→ Automatizar videos (1-3/día)
→ "Social media diario"
→ Elige tipos: Tips, Testimonios, Updates
→ Sistema crea automáticamente
```

**Editar tu video:**
```bash
# Coloca tu video en: public/assets/video.mp4
npm run cli
→ Sistema automáticamente:
  - Extrae transcripción (Whisper AI)
  - Detecta silencios
  - Genera subtítulos
  - Propone edición con overlays
```
